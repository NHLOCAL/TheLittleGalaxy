# הגלקסיה הקטנה 🌌

הרפתקת דפדפן תלת־ממדית בעברית בהשראת **הנסיך הקטן**: עשרה כוכבים, דמויות מונפשות, מפגשים קטנים והדרך חזרה הביתה.

המשחק מצייר מודלים אמיתיים עם Three.js — הנסיך, הוורד, הכבשה, השועל, המלך ושאר הדמויות — עם תאורה, צללים, תנועה וצעיף מתנופף. תמונות הדמויות הישנות נשמרו במאגר, אך אינן משמשות לציור הדמויות במשחק החדש.

הנסיך נבנה כדמות המרכזית עם פנים מפוסלות, עיניים מבריקות ומצמוץ עדין, שיער זהוב, בגדי בד, ידיים מפורטות וצעיף רציף שמתנופף ברוח. במעוף הוא פורס זרועות, מכופף ברכיים ונוטה לתוך הפניות; כל דמות משנה מקבלת לבוש, הבעה ואביזרים משלה. הכוכבים משלבים מכתשים, דיונות, שבילים, צמחייה והרי געש לפי אופיים.

## שני מצבים

- **מסע סיפורי:** משלימים את המפגשים כדי לפתוח את המפגש עם הנחש. ההתקדמות נספרת בסיום שיחה ונשמרת מקומית בדפדפן.
- **חקירה חופשית:** כל הכוכבים פתוחים מיד. עוברים ביניהם בעזרת כפתורי הכוכב הקודם/הבא או המפה, ללא צורך בשליטה ידנית, סדר ביקור או השלמת שיחות. אפשר גם לעוף ידנית בעזרת החצים. המצב אינו מעניק התקדמות למסע הסיפורי.

לאחר השיחה עם הנחש, הוא מתקרב ונושך בעדינות, והנסיך ממריא במסלול קמור ורך ישירות לכוכב האם שלו, עם מצלמה מלווה ונחיתה ליד הוורד. המעוף מצויר ברציפות, והסיום מאפשר מסע חדש או המשך טיול חופשי.

## שליטה

| פעולה | שליטה |
| --- | --- |
| מעוף ידני בשני המצבים | מקשי החצים, לפי הכיוון על המסך, עם תאוצה ובלימה רכות |
| מעבר אוטומטי בין כוכבים | כפתורי הכוכב הקודם/הבא |
| בחירת כוכב | לחיצה על הכוכב במפה; במסך צר אפשר להחליק את המפה |
| שיחה והמשך | רווח, E או הכפתור שעל המסך |
| סגירת שיחה בלי להשלים אותה | Escape או כפתור הסגירה |
| תנועה במגע | בקר התנועה שעל המסך |

בהגדרות אפשר לבחור איכות תצוגה, תנועה מופחתת ואיפוס התקדמות. הצליל כבוי כברירת מחדל וניתן להפעילו בכפתור הצליל. העדפת המערכת לתנועה מופחתת מכובדת.

## הפעלה מקומית

דרושים Node.js 20 ומעלה ו-Python 3. המשחק עצמו פועל בדפדפן מעודכן עם WebGL 2.

```bash
npm ci --cache /tmp/little-galaxy-npm --ignore-scripts
npm run vendor
npm run dev
```

שרת הפיתוח משרת את תיקיית המאגר בפורט 8000. `npm run vendor` מעתיק את המודולים והגופנים מהחבילות הנעולות. העותקים המקומיים נשמרים ב-`assets/vendor` וב-`assets/fonts`; המשחק אינו טוען ספרייה או גופן מ-CDN.

הפצה סטטית דרך GitHub Pages נשארת נתמכת, כולל נתיב `/TheLittleGalaxy/`. אין צורך בשרת יישום, מסד נתונים, חשבון או מפתח API. קובצי `assets/vendor`, הגופנים ורקע החלל צריכים להיכלל בהפצה.

## בדיקות

```bash
npm test
node tests/browser_controls.mjs
python3 tests/browser_smoke.py
python3 tests/browser_edges.py
python3 tests/browser_fallbacks.py
```

בדיקות Node מכסות דיאלוגים, פתיחת הנחש, הפרדה בין המצבים, שמירה, מסלול תעופה ואיפוס. בדיקות הדפדפן מפעילות את המשחק המרונדר: ניווט, כל הדיאלוגים, מעוף ונחיתה, התחלה מחדש, שליטה במגע, מיקוד מקלדת ושחזור דף.

בדיקות הדפדפן דורשות שרת פיתוח פעיל, Python Playwright ו-Chromium. בסביבת הענן הם מותקנים. אפשר להגדיר `GALAXY_TEST_URL` ו-`GALAXY_CHROMIUM` לשרת ולנתיב דפדפן אחרים. צילומי הבדיקות נשמרים ב-`/tmp`, מחוץ למאגר. רינדור תוכנתי בסביבת הבדיקות אינו מדד לביצועי GPU במכשיר משתמש.

בדיקת החיצים הנפרדת ב-Node דורשת `playwright-core`. אפשר להגדיר `GALAXY_PLAYWRIGHT_MODULE` לנתיב החבילה הזמינה במחשב. היא בודקת מעוף עם כל ארבעת החצים בשני המצבים, המראה וריחוף, עצירה באובדן מיקוד, ניווט בכפתורים ושליטה במגע.

## מבנה

נתוני הסיפור נמצאים ב-`code/story.js`, מצב המשחק ב-`code/state.js`, דמות הנסיך ב-`code/prince.js`, וחומרי המידול שלה ב-`code/sculpt.js`. דמויות המשנה והאביזרים נמצאים ב-`code/characters.js`, התאוצה והבלימה ב-`code/motion.js`, והעולם והמצלמה ב-`code/scene.js`. הקלט, הממשק, השמע והשמירה מופרדים למודולים משלהם. `code/game.js` מחבר אותם ומפעיל לולאת רינדור רציפה.
